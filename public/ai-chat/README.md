# WebLLM AI チャットウィジェット

このフォルダは、サーバーや API キーを使わず、訪問者のブラウザ内だけで動く AI チャットです。WebGPU と [WebLLM](https://github.com/mlc-ai/web-llm) を利用します。

## 導入

静的サイトでは、次の 1 行を `</body>` の直前に追加します。

```html
<script type="module" src="/ai-chat/chat-widget.js"></script>
```

このポートフォリオでは `app/layout.tsx` に組み込み済みです。GitHub Pages の公開先が `/official/` のため、ビルド時には `/official/ai-chat/chat-widget.js` として読み込まれます。

## ファイル

- `persona.js`: AI の話し方・価値観・回答上の約束です。公開ファイルなので、パスワードや非公開情報は書かないでください。
- `chat-widget.js`: UI、遅延ロード、会話履歴、ストリーミング応答を担当します。
- `chat-widget.css`: `--ai-chat-primary` などの CSS 変数で色を調整できます。

## 動作と注意点

- 初めてチャットを開いたときだけ、標準モデル `Llama-3.2-3B-Instruct-q4f16_1-MLC` をダウンロードします。読み込みに失敗した場合は、軽量な `Llama-3.2-1B-Instruct-q4f16_1-MLC` を試します。
- モデルはブラウザのキャッシュに保存されるため、初回は通信量と待ち時間が大きくなります。公開サイトの読み込み時にはダウンロードしません。
- WebGPU が必要です。最新の Chrome / Edge を推奨します。非対応環境では案内だけを表示します。
- 会話はページを再読み込みすると消えます。会話内容をサーバーへ送信したり、API キーを使用したりしません。
- CDN とモデル配信元に接続できるネットワーク環境が必要です。
- チャットを開くと、個人ブログの公開済み記事を最大8件読み込みます。質問に近い記事だけを回答時の情報源として使います。取得できない環境でも、通常の対話機能は利用できます。
- 「ブログに書いてある？」「この記事はどこ？」のように尋ねて関連箇所が見つかった場合、該当記事の本文箇所をブラウザ標準のテキストハイライトで開きます。対応していないブラウザでは、同じ記事を通常表示します。

## 人格を編集する

`persona.js` の `PERSONA_SECTIONS` の文章を編集します。すべてを結合した `SYSTEM_PROMPT` が毎回の会話の先頭に渡されます。長い文章を入れすぎると生成が遅くなるため、要点を短く保つことをおすすめします。ブログの参照先は同ファイルの `BLOG_HOME_URL` で変更できます。
